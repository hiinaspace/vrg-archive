About this archive

An archive of the 4chan /vg/ /vrg/ (Virtual Reality General) threads, searchable in your browser. There is no server: the search runs in JavaScript over static index files. There is no search server and no query logging; your query lives in the page URL.

What is indexed

__POSTS__ posts in __THREADS__ threads, __FIRST__ to __LAST__ (UTC). The data came from the 4chan API (2025-04 onward), from an earlier archive export (before that), and from b4k (arch.b4k.dev) for posts and thumbnails the other sources missed. Only threads whose last post is more than 7 days old are published, so moderator deletions have settled first. Data as of __SNAP__.

Posts known to be deleted are excluded everywhere: not in the search index, not on thread pages, not in quote previews. The 2016–2025-04 export carries no deletion flags, so a post deleted on 4chan in that era can still appear here; ask for a takedown below. A >>N that points at a missing or excluded post is shown as plain text. Images are never served in full. Thumbnails are the small previews 4chan published, shown only for posts whose file was not deleted; spoilered thumbnails stay blurred until clicked. Older posts show a placeholder with the file name and dimensions instead.

Takedowns

To have a post, thread or image removed, contact hiina@hiina.space with the post number (No.123456789). Removals are listed in excluded_ids.txt and applied at the next build; urgent ones are rebuilt by hand.

Data export

The old version of this site offered a downloadable DuckDB/Parquet dump of the archive. A full data export is still available on request: contact hiina@hiina.space.

Search syntax

quest proall words (case-insensitive; digits count; plurals are folded)
"exact phrase"words next to each other
-word, a | b, (a | b) cexclude, either, grouping. OR binds tighter than a space
thread:1978one thread (edition number or thread id)
after:2023-05 before:2024date range; date:2023, date:2023-01..2023-06, date:>=2024
has:image, ext:png, has:linkimage posts, file type (jpg png gif webm mp4), posts with links
op:yesfirst posts of threads
replies:>=5posts with at least that many replies
domain:youtube.composts linking a site (the commonest sites only)
name:foo, trip:abc123poster name or tripcode (almost all posts are Anonymous)
filename:vrchatwords in the posted file's name
greentext:implyingonly inside >greentext lines
>>585933859replies to that post

Japanese, Chinese and Korean text is matched as character pairs. Very common words (the, a, to ...) are ignored when the query has other words. Quote numbers are not searchable as words. Facet counts cover every post matching the query and all filters.
